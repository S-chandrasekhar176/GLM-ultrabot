    11→## 1.1 Project Name
    12→
    13→**UltraBot Web** — Algorithmic Trading Terminal for NSE
    14→
    15→## 1.2 One-Line Description
    16→
    17→A semi-automated, web-based algorithmic trading system for Indian NSE markets that scans stocks using news + technical analysis, identifies high-probability opportunities through adaptive strategies + AI scoring, presents them to the user with full probability analysis for confirmation, and executes with dynamic position sizing, partial profit booking, and multi-layer risk management.
    18→
    19→## 1.3 Core Philosophy
    20→
    21→```
    22→1. News tells WHERE to look     (watchlist builder)
    23→2. Strategies tell WHEN to trade (signal generator)
    24→3. Risk engine tells WHETHER to trade (safety net)
    25→4. User gives FINAL YES/NO      (human in the loop)
    26→5. System executes HOW MUCH     (dynamic sizing)
    27→6. System manages EXIT          (partial booking + trailing SL)
    28→```
    29→
    30→## 1.4 Target User
    31→
    32→Single user (you). Private. Personal trading terminal. Not a public product.
    33→
    34→## 1.5 Target Market
    35→
    36→Indian National Stock Exchange (NSE) — Equity Segment + Options Segment (NFO)

   108→## 2.2 Data Flow — Complete Pipeline
   109→
   110→```
   111→PRE-MARKET (8:00 - 9:15 AM)
   112→━━━━━━━━━━━━━━━━━━━━━━━━━━━
   113→  1. News Engine fetches overnight news
   114→     → NSE corporate actions
   115→     → Result calendar for today
   116→     → Moneycontrol/ET RSS feeds
   117→     → Bulk/block deals from yesterday
   118→  
   119→  2. News Engine builds Morning Watchlist
   120→     → Stocks with news catalyst
   121→     → Stocks with results today
   122→     → Stocks with corporate actions
   123→  
   124→  3. Technical Pre-Scan on F&O universe (185 stocks)
   125→     → Gap detection (pre-market prices)
   126→     → Previous day breakouts near completion
   127→     → Stocks with unusual volume yesterday
   128→  
   129→  4. Merge → Morning Watchlist (20-40 stocks)
   130→  
   131→  5. Telegram: Morning briefing sent
   132→     "Today's watchlist: RELIANCE, INFY, TCS..."
   133→     "Key events: INFY Q3 results, HDFCBANK ex-dividend"
   134→
   135→
   136→MARKET OPEN (9:15 AM)
   137→━━━━━━━━━━━━━━━━━━━━━━
   138→  6. WebSocket connects to broker (Angel One / Shoonya)
   139→     → Live prices stream for watchlist stocks
   140→     → Candle data (1min, 5min, 15min) building
   141→  
   142→  7. Market Regime Detector runs
   143→     → Analyzes Nifty trend, VIX, sector movement
   144→     → Classifies: Bull / Bear / Sideways / Volatile
   145→     → Activates appropriate strategies
   146→     → Deactivates inappropriate strategies
   147→  
   148→  8. SCANNING LOOP (every 1-5 minutes)
   149→     │
   150→     ├── Kronos Scanner
   151→     │   → Scans watchlist stocks
   152→     │   → Ranks by opportunity score
   153→     │   → Updates hot list ranking
   154→     │
   155→     ├── Strategy Engine
   156→     │   → Each active strategy checks each watchlist stock
   157→     │   → Generates signals (entry, SL, target, direction)
   158→     │   → Kronos scores each signal (confidence 0-1)
   159→     │
   160→     ├── Risk Engine (13 Gates)
   161→     │   → G1:  Max open positions
   162→     │   → G2:  Max sector concentration
   163→     │   → G3:  Max position size
   164→     │   → G4:  Max daily trades
   165→     │   → G5:  Max daily loss
   166→     │   → G6:  Correlation check
   167→     │   → G7:  VIX filter
   168→     │   → G8:  Time-of-day filter
   169→     │   → G9:  Price mismatch guard
   170→     │   → G10: Min signal confidence
   171→     │   → G11: Max drawdown
   172→     │   → G12: Margin check
   173→     │   → G13: Duplicate signal check
   174→     │
   175→     ├── Dynamic Position Sizer
   176→     │   → Kelly base fraction
   177→     │   → Adjust for signal confidence
   178→     │   → Adjust for VIX/volatility
   179→     │   → Adjust for current drawdown
   180→     │   → Adjust for available capital
   181→     │   → Check minimum position size
   182→     │   → Final quantity determined
   183→     │
   184→     └── If signal passes all gates + sizing OK:
   185→         → OPPORTUNITY PRESENTED TO USER
   186→  
   187→  9. OPPORTUNITY PRESENTED (WebSocket push to browser)
   188→     │
   189→     ├── Browser shows confirmation dialog:
   190→     │   • Stock name, direction (BUY/SELL)
   191→     │   • Strategy name + historical win rate
   192→     │   • Entry, SL, Target, R:R ratio
   193→     │   • Kronos confidence score
   194→     │   • Position size + capital required
   195→     │   • Equity trade details + Options trade details
   196→     │   • All 13 risk gate results
   197→     │   • Market context (VIX, Nifty trend, sector)
   198→     │   • Backtest stats for this strategy+stock combo
   199→     │
   200→     ├── User clicks CONFIRM → order placed
   201→     │   ├── Paper mode: simulated in memory + DB
   202→     │   └── Live mode: sent to broker API
   203→     │
   204→     ├── User clicks SKIP → logged as skipped
   205→     │
   206→     └── User clicks REMIND → re-alert after X minutes
   207→  
   208→  10. POSITION MANAGEMENT (continuous while position open)
   209→      │
   210→      ├── Price hits Level 1 (1:1 R:R)
   211→      │   → Book 50% quantity
   212→      │   → Move SL to entry (risk-free)
   213→      │   → Telegram: partial booking alert
   214→      │
   215→      ├── Price hits Level 2 (1.5:1 R:R)
   216→      │   → Book 25% quantity
   217→      │   → Trail SL
   218→      │
   219→      ├── Price hits Target (2:1 R:R)
   220→      │   → Exit remaining or trail
   221→      │
   222→      ├── Price hits SL
   223→      │   → Exit full quantity
   224→      │   → Record loss
   225→      │   → Check daily loss limit
   226→      │
   227→      └── Trailing SL keeps moving
   228→          → If price reverses, SL triggers exit
   229→  
   230→  11. DAILY RISK MONITORING
   231→      │
   232→      ├── Track daily P&L continuously
   233→      ├── At 67% of max daily loss → reduce new position size 50%
   234→      ├── At 100% of max daily loss → STOP new trades for day
   235→      ├── At 5 consecutive losses → cool-off 30 minutes
   236→      ├── At max daily trades → no new trades
   237→      └── All limits configurable by user
   238→
   239→
   240→POST-MARKET (3:30 - 4:00 PM)
   241→━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   242→  12. Square off all intraday positions
   243→  13. Calculate final P&L with fees
   244→  14. Save session state to SQLite
   245→  15. Generate EOD report
   246→  16. Send EOD via Telegram
   247→  17. Prepare next-day hints
   248→```

   799→## 3.4 Risk Gates — Detailed Specification
   800→
   801→```
   802→GATE 1: MAX OPEN POSITIONS
   803→━━━━━━━━━━━━━━━━━━━━━━━━━━
   804→  Check:    current_open_positions >= max_positions
   805→  Default:  max_positions = 5
   806→  Action:   REJECT if limit reached
   807→  Config:   User can change max_positions
   808→
   809→
   810→GATE 2: SECTOR CONCENTRATION
   811→━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   812→  Check:    How many positions already in same sector as new signal
   813→  Default:  max_per_sector = 2
   814→  Action:   REJECT if sector limit reached
   815→  Why:      Don't put all money in banking if you already have 2 bank stocks
   816→  Sectors:  Banking, IT, Energy, Pharma, Auto, FMCG, Infra, Metal, etc.
   817→
   818→
   819→GATE 3: MAX POSITION SIZE
   820→━━━━━━━━━━━━━━━━━━━━━━━━━━
   821→  Check:    position_value > max_position_pct × total_capital
   822→  Default:  max_position_pct = 25%
   823→  Action:   REJECT if exceeds (or resize if possible)
   824→  Also:     Check available capital (balance aware)
   825→
   826→
   827→GATE 4: MAX DAILY TRADES
   828→━━━━━━━━━━━━━━━━━━━━━━━━━━
   829→  Check:    trades_today >= max_daily_trades
   830→  Default:  max_daily_trades = 10
   831→  Action:   REJECT new signals for rest of day
   832→
   833→
   834→GATE 5: MAX DAILY LOSS
   835→━━━━━━━━━━━━━━━━━━━━━━━━━━
   836→  Check:    daily_pnl <= -max_daily_loss
   837→  Default:  max_daily_loss = 3% of capital
   838→  Action:   REJECT new trades + tighten existing SLs
   839→  Warning:  At 67% usage → reduce new position sizes by 50%
   840→
   841→
   842→GATE 6: CORRELATION CHECK
   843→━━━━━━━━━━━━━━━━━━━━━━━━━━
   844→  Check:    Is new signal highly correlated with existing positions?
   845→  Default:  max_correlated = 2
   846→  Action:   REJECT if too many correlated positions
   847→  Example:  Already have SBI + HDFCBANK → reject PNB (all banking)
   848→
   849→
   850→GATE 7: VIX FILTER
   851→━━━━━━━━━━━━━━━━━━
   852→  Check:    current_vix > vix_threshold
   853→  Default:  vix_threshold = 20
   854→  Action:   REJECT new trades when VIX too high
   855→  Why:      High VIX = high volatility = unpredictable = dangerous
   856→
   857→
   858→GATE 8: TIME OF DAY
   859→━━━━━━━━━━━━━━━━━━━━━
   860→  Check:    Current time outside preferred trading window
   861→  Default:  New trades: 9:30 AM - 2:30 PM only
   862→  Action:   REJECT new trades outside window
   863→  Why:      First 15 min = ORB formation. Last hour = squaring off.
   864→  Note:     Can configure different windows per strategy
   865→
   866→
   867→GATE 9: PRICE MISMATCH GUARD
   868→━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   869→  Check:    |signal_entry_price - broker_live_ltp| / broker_live_ltp > threshold
   870→  Default:  threshold = 0.5%
   871→  Action:   REJECT + refresh feed + alert
   872→  Why:      Prevents trading on stale/hallucinated prices
   873→  Critical: This is the P0 bug guard
   874→
   875→
   876→GATE 10: MINIMUM SIGNAL CONFIDENCE
   877→━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   878→  Check:    kronos_score < min_confidence
   879→  Default:  min_confidence = 0.6
   880→  Action:   REJECT low-confidence signals
   881→  Why:      Don't trade weak signals. Wait for strong ones.
   882→
   883→
   884→GATE 11: MAX DRAWDOWN
   885→━━━━━━━━━━━━━━━━━━━━━━━
   886→  Check:    current_drawdown > max_drawdown_pct
   887→  Default:  max_drawdown_pct = 5% (per day)
   888→  Action:   PAUSE engine + alert
   889→  Different: From G5 (daily loss). This tracks peak-to-trough.
   890→
   891→
   892→GATE 12: MARGIN CHECK
   893→━━━━━━━━━━━━━━━━━━━━━━━
   894→  Check:    required_margin > available_margin
   895→  Action:   REJECT or RESIZE to fit available margin
   896→  Live mode: Check actual broker margin
   897→  Paper mode: Check virtual capital
   898→
   899→
   900→GATE 13: DUPLICATE SIGNAL
   901→━━━━━━━━━━━━━━━━━━━━━━━━━━
   902→  Check:    Same symbol + same direction signal in last X minutes?
   903→  Default:  X = 15 minutes
   904→  Action:   REJECT duplicate (keep first one)
   905→  Why:      Multiple strategies may fire same signal. Take only first.
   906→```

   910→## 3.5 Dynamic Position Sizing — Detailed Logic
   911→
   912→```
   913→STEP 1: BASE KELLY FRACTION
   914→━━━━━━━━━━━━━━━━━━━━━━━━━━━
   915→  win_rate     = from strategy_performance table (historical)
   916→  avg_win      = average winning trade pnl
   917→  avg_loss     = average losing trade pnl
   918→  kelly_f      = (win_rate × avg_win - (1 - win_rate) × avg_loss) / avg_win
   919→  kelly_f      = clamp(kelly_f, 0.02, 0.25)  // Never below 2%, never above 25%
   920→  
   921→  base_size    = total_capital × kelly_f
   922→
   923→
   924→STEP 2: CONFIDENCE ADJUSTMENT
   925→━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   926→  kronos_score = signal.confidence  (0 to 1)
   927→  
   928→  if kronos_score >= 0.8:   confidence_mult = 1.0    (strong signal)
   929→  if kronos_score >= 0.6:   confidence_mult = 0.8    (decent signal)
   930→  if kronos_score >= 0.4:   confidence_mult = 0.5    (weak signal)
   931→  if kronos_score <  0.4:   REJECT by G10           (too weak)
   932→  
   933→  adjusted_size = base_size × confidence_mult
   934→
   935→
   936→STEP 3: VOLATILITY ADJUSTMENT
   937→━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   938→  vix = current_vix
   939→  
   940→  if vix <= 14:   vol_mult = 1.0    (calm market, normal size)
   941→  if vix <= 18:   vol_mult = 0.85   (slightly nervous)
   942→  if vix <= 22:   vol_mult = 0.65   (worried, reduce)
   943→  if vix >  22:   vol_mult = 0.4    (fearful, much smaller)
   944→  
   945→  adjusted_size = adjusted_size × vol_mult
   946→
   947→
   948→STEP 4: DRAWDOWN ADJUSTMENT
   949→━━━━━━━━━━━━━━━━━━━━━━━━━━━
   950→  daily_pnl_pct = day_pnl / total_capital
   951→  
   952→  if daily_pnl_pct >= 0:      dd_mult = 1.0    (profitable day, normal)
   953→  if daily_pnl_pct >= -1%:    dd_mult = 0.9    (small loss, slight reduce)
   954→  if daily_pnl_pct >= -2%:    dd_mult = 0.7    (moderate loss, reduce)
   955→  if daily_pnl_pct >= -3%:    dd_mult = 0.4    (approaching limit, heavy reduce)
   956→  if daily_pnl_pct <  -3%:    STOP new trades  (limit hit)
   957→  
   958→  adjusted_size = adjusted_size × dd_mult
   959→
   960→
   961→STEP 5: CAPITAL AVAILABILITY
   962→━━━━━━━━━━━━━━━━━━━━━━━━━━━
   963→  available = free_capital × 0.9   (never use 100%)
   964→  
   965→  if adjusted_size <= available:
   966→      final_size = adjusted_size   (we can afford it)
   967→  else:
   968→      final_size = available       (cap at what we can afford)
   969→  
   970→  if final_size < min_position_size (e.g., ₹5,000):
   971→      REJECT: "Position too small after adjustments"
   972→
   973→
   974→STEP 6: CONVERT TO QUANTITY
   975→━━━━━━━━━━━━━━━━━━━━━━━━━━━
   976→  qty = floor(final_size / entry_price)
   977→  
   978→  if segment == "OPT":
   979→      lot_size = option_lot_size[symbol]  (e.g., RELIANCE lot = 250)
   980→      qty = floor(final_size / (premium × lot_size)) × lot_size
   981→  
   982→  final_capital_required = qty × entry_price  (or qty × premium × lot_size for options)
   983→```

   987→## 3.6 Partial Profit Booking — Detailed Logic
   988→
   989→```
   990→WHEN POSITION IS OPENED:
   991→━━━━━━━━━━━━━━━━━━━━━━━━
   992→  entry  = position.entry_price
   993→  sl     = position.sl_price
   994→  target = position.target_price
   995→  qty    = position.total_quantity
   996→  
   997→  risk   = |entry - sl|                          (risk per share)
   998→  
   999→  level1_target = entry + (risk × 1.0)          (1:1 R:R)
  1000→  level2_target = entry + (risk × 1.5)          (1.5:1 R:R)
  1001→  level3_target = entry + (risk × 2.0)          (2:1 R:R) = original target
  1002→  
  1003→  (For SELL positions, subtract instead of add)
  1004→
  1005→
  1006→LEVEL 1 HIT: price reaches level1_target
  1007→━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1008→  book_qty    = ceil(qty × 0.50)                (book 50%)
  1009→  remaining   = qty - book_qty
  1010→  book_pnl    = book_qty × |level1_target - entry|
  1011→  
  1012→  Action:
  1013→    → Exit book_qty shares at level1_target
  1014→    → Move SL to entry price (risk-free now)
  1015→    → Record partial booking in position.booked_levels
  1016→    → Telegram: "Partial booking L1: {symbol} {book_qty} shares @ {level1_target}"
  1017→    → WebSocket: push updated position to browser
  1018→
  1019→
  1020→LEVEL 2 HIT: price reaches level2_target
  1021→━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1022→  book_qty    = ceil(remaining × 0.50)          (book 50% of remaining = 25% of original)
  1023→  remaining   = remaining - book_qty
  1024→  book_pnl    = book_qty × |level2_target - entry|
  1025→  
  1026→  Action:
  1027→    → Exit book_qty shares at level2_target
  1028→    → Trail SL to level1_target (locked L1 profit)
  1029→    → Record partial booking
  1030→    → Telegram: "Partial booking L2: {symbol} {book_qty} shares @ {level2_target}"
  1031→
  1032→
  1033→LEVEL 3 HIT: price reaches level3_target (original target)
  1034→━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1035→  Option A: Exit remaining shares at target
  1036→  Option B: Trail SL with Supertrend and let it run (if momentum is strong)
  1037→  
  1038→  Default: Option A (exit at target)
  1039→  Config:  User can choose Option B per strategy
  1040→
  1041→
  1042→TRAILING STOP LOSS
  1043→━━━━━━━━━━━━━━━━━━━
  1044→  After Level 1 booked (risk-free):
  1045→    → Trail SL method: Step trail or Supertrend trail
  1046→    
  1047→    Step Trail:
  1048→      → Every time price moves +1% from last SL, move SL up by 0.5%
  1049→      → SL never moves down
  1050→    
  1051→    Supertrend Trail:
  1052→      → Use Supertrend indicator as trailing SL
  1053→      → More adaptive, follows price action
  1054→```

  1424→## 3.11 Strategies — Detailed Specifications
  1425→
  1426→```
  1427→CORE STRATEGIES (7):
  1428→━━━━━━━━━━━━━━━━━━━━
  1429→
  1430→1. BREAKOUT
  1431→   ─────────
  1432→   Logic:      Price breaks above resistance or below support with volume
  1433→   Entry:      Close > Resistance + buffer (or Close < Support - buffer)
  1434→   SL:         Resistance level (or Support level)
  1435→   Target:     Entry + 2× risk (or next resistance level)
  1436→   Volume:     Must be 1.5× average volume on breakout candle
  1437→   Timeframe:  5min, 15min
  1438→   Best in:    Bull, Bear (shorts)
  1439→   Worst in:   Sideways (false breakouts)
  1440→
  1441→2. MEAN REVERSION
  1442→   ───────────────
  1443→   Logic:      Price deviated far from mean, expected to snap back
  1444→   Entry:      Z-score of (price - SMA) > 2.0 (oversold) or < -2.0 (overbought)
  1445→   SL:         Entry ± 1.5× standard deviation
  1446→   Target:     SMA (mean)
  1447→   Timeframe:  5min, 15min
  1448→   Best in:    Sideways
  1449→   Worst in:   Strong trends (gets destroyed)
  1450→
  1451→3. MOMENTUM
  1452→   ─────────
  1453→   Logic:      Strong directional move with increasing volume
  1454→   Entry:      Rate of change > threshold AND volume > 2× average
  1455→   SL:         Entry - 1× ATR
  1456→   Target:     Entry + 2× ATR
  1457→   Timeframe:  5min
  1458→   Best in:    Bull, Bear
  1459→   Worst in:   Choppy, sideways
  1460→
  1461→4. OPENING RANGE BREAKOUT (ORB)
  1462→   ─────────────────────────────
  1463→   Logic:      Break of first 15-30 minute high/low
  1464→   Entry:      Price > Opening Range High (BUY) or < Opening Range Low (SELL)
  1465→   SL:         Opening Range midpoint or opposite end
  1466→   Target:     Entry + 2× risk
  1467→   Volume:     Breakout candle volume > OR average volume
  1468→   Timeframe:  5min (range built on 15min candles from 9:15-9:30)
  1469→   Best in:    All regimes (especially trending)
  1470→   Time gate:  Only between 9:30 - 11:00 AM
  1471→
  1472→5. RSI DIVERGENCE
  1473→   ───────────────
  1474→   Logic:      Price makes new high but RSI doesn't (bearish divergence) or vice versa
  1475→   Entry:      On divergence + confirmation candle
  1476→   SL:         Recent swing high/low
  1477→   Target:     Entry - 2× risk (bearish) or Entry + 2× risk (bullish)
  1478→   RSI period: 14
  1479→   Timeframe:  15min
  1480→   Best in:    Reversals, Bear trend
  1481→   Worst in:   Strong bull trend
  1482→
  1483→6. SUPERTREND
  1484→   ───────────
  1485→   Logic:      Follow Supertrend indicator direction changes
  1486→   Entry:      Supertrend flips from sell→buy (BUY) or buy→sell (SELL)
  1487→   SL:         Supertrend value (it acts as trailing SL)
  1488→   Target:     Entry + 2× ATR (or trail with Supertrend)
  1489→   Params:     Period=10, Multiplier=3
  1490→   Timeframe:  5min, 15min
  1491→   Best in:    Bull, Bear
  1492→   Worst in:   Sideways (whipsaws)
  1493→
  1494→7. VWAP REVERSION
  1495→   ───────────────
  1496→   Logic:      Price deviated far from VWAP, expected to revert
  1497→   Entry:      Price > VWAP + 2× StdDev (overbought, SELL) or Price < VWAP - 2× StdDev (oversold, BUY)
  1498→   SL:         VWAP ± 3× StdDev
  1499→   Target:     VWAP
  1500→   Timeframe:  5min
  1501→   Best in:    Sideways, intraday
  1502→   Worst in:   Strong trends
  1503→
  1504→
  1505→ADVANCED STRATEGIES (7):
  1506→━━━━━━━━━━━━━━━━━━━━━━━━
  1507→
  1508→8. GAP FILL
  1509→   ─────────
  1510→   Logic:      Gap up/down at open. Trade the gap fill (price returns to previous close)
  1511→   Entry:      If gap up > 0.5% AND first 5-min candle is red → SELL (gap fill)
  1512→               If gap down > 0.5% AND first 5-min candle is green → BUY (gap fill)
  1513→   SL:         Day's high/low
  1514→   Target:     Previous close (gap fill target)
  1515→   Timeframe:  1min, 5min
  1516→   Best in:    Gap days
  1517→   Time gate:  9:15 - 10:30 AM only
  1518→
  1519→9. SECTOR ROTATION
  1520→   ────────────────
  1521→   Logic:      When a sector starts outperforming, trade the strongest stock in that sector
  1522→   Entry:      Sector momentum > threshold → buy strongest stock in sector
  1523→   SL:         Sector ETF/indicator level breakdown
  1524→   Target:     Entry + 2× risk
  1525→   Timeframe:  15min
  1526→   Best in:    Sector rotation days
  1527→
  1528→10. MULTI-TIMEFRAME CONFLUENCE
  1529→    ───────────────────────────
  1530→   Logic:      Signal valid only when 2+ timeframes agree
  1531→   Entry:      5min trend = 15min trend = 1hr trend (all same direction)
  1532→   SL:         Based on 5min ATR
  1533→   Target:     Entry + 2× risk (15min based)
  1534→   Timeframe:  5min + 15min + 60min
  1535→   Best in:    All (reduces false signals in any regime)
  1536→
  1537→11. ORB + VOLUME CONFIRMATION
  1538→    ──────────────────────────
  1539→   Logic:      ORB breakout but with strong volume confirmation (2×+ OR volume)
  1540→   Entry:      Same as ORB but volume must be 2×+ opening range average
  1541→   SL:         Same as ORB
  1542→   Target:     Same as ORB
  1543→   Best in:    Bull, Bear (filters false breakouts better than plain ORB)
  1544→
  1545→12. TREND EXHAUSTION
  1546→    ────────────────
  1547→   Logic:      Trend running too long + momentum decreasing + divergence appearing
  1548→   Entry:      After 3+ Supertrend direction candles + decreasing RSI + volume declining
  1549→   SL:         Recent swing high/low
  1550→   Target:     Entry - 1.5× risk (counter-trend)
  1551→   Best in:    End of trends, reversals
  1552→   Risk:       Higher risk (counter-trend). Size reduced automatically.
  1553→
  1554→13. NEWS MOMENTUM
  1555→    ──────────────
  1556→   Logic:      After news catalyst, wait for first pullback then enter in news direction
  1557→   Entry:      Stock in news → initial move → pullback to VWAP/EMA → entry in original direction
  1558→   SL:         Pullback low (or high for shorts)
  1559→   Target:     Entry + 2× risk
  1560→   Best in:    Post-news, trending
  1561→   Requires:   News Engine + technical confirmation
  1562→
  1563→14. ADAPTIVE SUPERTREND
  1564→    ────────────────────
  1565→   Logic:      Supertrend that auto-adjusts multiplier based on VIX
  1566→   Params:     Base period=10, Multiplier = 3 + (VIX-15)/10
  1567→               Low VIX (12) → multiplier 2.5 (tighter, more signals)
  1568→               High VIX (25) → multiplier 3.5 (wider, fewer signals)
  1569→   Entry:      Same as Supertrend but with adaptive multiplier
  1570→   Best in:    All regimes (self-adapts)
  1571→```
