## 5. ERROR ENGINE (errors/)

### error_types.py:
Define custom exception hierarchy:
- `UltraBotError` (base)
  - `BrokerError` → `TokenExpiredError`, `OrderRejectedError`, `ConnectionLostError`
  - `FeedError` → `WebSocketDisconnectedError`, `StaleDataError`, `PriceMismatchError`
  - `StrategyError` → `InsufficientDataError`, `CalculationError`
  - `RiskError` → `DailyLimitError`, `RiskGateRejectionError`
  - `EngineError` → `EngineCrashError`, `SessionRecoveryError`

Each exception must have attributes: `error_type`, `severity`, `what_happened`, `why_happened`, `how_to_fix`, `context` (dict)

### error_context.py:
- `capture_context()` function that captures: current engine state, open positions count, active broker, active feed, current VIX, market regime, timestamp, and any additional kwargs
- Returns a dict ready for error log storage

### auto_recovery.py:
- `AutoRecovery` class with methods for each recoverable error type:
  - `recover_token_expired(broker)` → re-authenticate, return success/failure
  - `recover_websocket_disconnected(feed)` → reconnect with exponential backoff (5s, 10s, 20s, 40s, 80s), max 5 attempts, return success/failure
  - `recover_stale_data(feed)` → disconnect and reconnect feed, return success/failure
  - `recover_price_mismatch(signal, feed)` → refresh LTP from broker, recalculate signal prices, return updated signal or failure
  - Each method logs every attempt and result

### error_engine.py:
- `ErrorEngine` class (singleton) that:
  - `handle_error(exception, context_override=None)` → main entry point
    - Captures context via `capture_context()`
    - Generates unique error_code (format: ERR-YYYY-MMDD-NNNN)
    - Determines severity from exception
    - Attempts auto-recovery if applicable
    - Saves to error_logs table via repository
    - Sends to WebSocket subscribers (critical + warning only)
    - Sends to Telegram if critical
    - Returns error_log record
  - `resolve_error(error_id, resolution_note)` → mark as resolved
  - `get_errors(severity=None, resolved=None, limit=50)` → query error logs
  - `get_error_stats()` → aggregate stats by type and severity

```python
class NSEFeeCalculator:
    """Calculate all NSE charges for equity and options trades"""
    
    def calculate_equity_intraday(self, buy_price, sell_price, quantity, brokerage_per_order=20):
        """
        Calculate fees for intraday equity trade.
        Returns dict with: brokerage, stt, exchange_txn, gst, sebi, stamp_duty, total
        """
        # Buy side:
        #   Brokerage: flat per order
        #   STT: 0 (only on sell for intraday)
        #   Exchange: buy_price * qty * 0.0000345
        #   GST: 18% * (brokerage + exchange)
        #   SEBI: buy_price * qty * 0.000001
        #   Stamp: buy_price * qty * 0.00003
        #
        # Sell side:
        #   Brokerage: flat per order
        #   STT: sell_price * qty * 0.00025
        #   Exchange: sell_price * qty * 0.0000345
        #   GST: 18% * (brokerage + exchange)
        #   SEBI: sell_price * qty * 0.000001
        #   Stamp: 0 (only on buy)
        #
        # Total = sum of all
        # All values rounded to 2 decimal places

    def calculate_equity_delivery(self, buy_price, sell_price, quantity, brokerage_per_order=0):
        """Same structure but STT 0.1% on both sides, stamp on buy only"""

    def calculate_options(self, buy_premium, sell_premium, quantity, lot_size, brokerage_per_order=20):
        """
        Calculate fees for options trade.
        STT: 0.0625% on sell premium only
        Exchange: 0.055% on both sides (on premium)
        """

    def calculate_net_pnl(self, entry_price, exit_price, quantity, direction, segment="EQ", mode="intraday"):
```

```python
        if self.feed:
            return await self.feed.get_ltp(symbol)
        raise FeedError("No feed connected to paper broker")

        return {
            "available": self.available_capital,
            "used": self.used_capital,
            "total": self.capital
        }
    
    async def place_order(self, order):
        """
        Simulate order execution.
        1. Get real LTP from feed
        2. Calculate fees
        3. Update virtual capital
        4. Create position
        5. Save to DB
        """
        # Get real live price
        ltp = await self.get_ltp(order["symbol"])
        
        # Calculate required capital
        entry_value = ltp * order["quantity"]
        
        # Calculate fees
        fees = self.fee_calculator.calculate_equity_intraday(
            buy_price=ltp if order["direction"] == "BUY" else 0,
            sell_price=ltp if order["direction"] == "SELL" else 0,
            quantity=order["quantity"],
            brokerage_per_order=20
        )
        
        # Check capital
        if entry_value > self.available_capital * 0.9:
            return {"success": False, "error": "Insufficient capital", "required": entry_value, "available": self.available_capital}
        
        # Update capital
        if order["direction"] == "BUY":
            self.used_capital += entry_value
            self.available_capital -= entry_value
        else:
            self.used_capital += entry_value
            self.available_capital -= entry_value
        
        # Create virtual position
```

```python
class RiskEngine:
    """
    13-gate risk validation engine.
    Every signal must pass ALL gates before being presented as opportunity.
    """
    
    def __init__(self, config, repository, daily_risk_manager):
        self.gates = [
            G1MaxPositions(config),
            G2SectorConcentration(config),
            G3MaxPositionSize(config),
            G4MaxDailyTrades(config),
            G5MaxDailyLoss(config),
            G6CorrelationCheck(config),
            G7VIXFilter(config),
            G8TimeOfDay(config),
            G9PriceMismatch(config),
            G10MinConfidence(config),
            G11MaxDrawdown(config),
            G12MarginCheck(config),
            G13DuplicateSignal(config),
        ]
        self.daily_risk = daily_risk_manager
    
    async def validate(self, signal, context) -> RiskResult:
        """
        Run signal through all 13 gates.
        Returns RiskResult with:
          - passed: bool
          - gate_results: list of GateResult (gate_name, passed, reason, details)
          - rejection: None or GateResult of first failing gate
        """
        results = []
        for gate in self.gates:
            result = await gate.check(signal, context)
            results.append(result)
            if not result.passed:
                # Log risk event
                await self.daily_risk.record_gate_rejection(gate, result, signal)
                return RiskResult(passed=False, gate_results=results, rejection=result)
        return RiskResult(passed=True, gate_results=results, rejection=None)
```

```python
class UltraBotEngine:

        self.broker = None
        self.feed = None

    async def start(self, mode: EngineMode, broker_name: str, strategy_names: list = None):
        """
        Start the engine.
        1. Set state to STARTING
        2. Create broker via factory (paper or live)
        3. Authenticate broker
        4. Connect feed
        5. Create session in DB
        6. Recover state if resuming
        7. Initialize scanner, strategies, risk engine
        8. Set state to RUNNING
        9. Start main loop as background task
        10. Return success
        """
    
    async def stop(self):
        """Graceful shutdown. Save state. Close positions if configured. Close session."""
    
    async def pause(self):
        """Pause scanning. Existing positions still managed."""
    
    async def resume(self):
        """Resume scanning."""
    
    async def _main_loop(self):
        """
        Main engine loop. Runs continuously while state == RUNNING.
        
        Every iteration:
          1. Check if market is open
          2. Update position prices from feed
          3. Check partial booking levels for all open positions
          4. Check trailing SLs for all open positions
          5. Check daily risk limits
          6. If market open AND in trade window AND not paused AND daily risk OK:
             a. Run scanner (get hot watchlist)
             b. Run strategies on watchlist stocks (get signals)
             c. For each signal:
                - Run risk gates
                - If passed: calculate position size
                - If size OK: create Opportunity, push to WebSocket
             d. Clean up expired opportunities
          7. Sleep for scan_interval
        """
    
    async def confirm_opportunity(self, opportunity_id, segment="EQ"):
        """
        User confirmed an opportunity.
        1. Get opportunity from pending list
        2. Re-verify risk gates (market may have changed)
        3. Re-check price mismatch
        4. Execute via broker
        5. Save trade to DB
        6. Push trade fill via WebSocket
        7. Send Telegram alert
        8. Return trade details
        """
    
    async def skip_opportunity(self, opportunity_id, reason=None):
        """Mark opportunity as skipped. Log reason."""
```
